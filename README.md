# Бегущий в лабиринте — фанатская 3D-игра

Играть: **https://diascsshtml.github.io/maze-runner/**

Неофициальная фанатская игра по «Бегущему в лабиринте» прямо в браузере: Глэйд, Лабиринт, гриверы, ночная жизнь.
Модели сделаны в Blender (люди — MakeHuman/MPFB, CC0), часть моделей и текстур — Poly Haven (CC0), 3D — three.js.
